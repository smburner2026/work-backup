# Research Pipeline — How Agents and Historians Actually Do the Work

## Phase 1: Source Acquisition

### For Burckhardt (Cultural History)
**What:** Literature, poetry, theater, newspapers, religious texts, art, architecture, folk songs, proverbs, daily life records.
**Where:** Gallica, Internet Archive, Vietnamese National Library, EFEO, JSTOR/MUSE, family materials.
**Agent workflow:** Search Gallica → Internet Archive → JSTOR/MUSE → cross-reference with VSTB.

### For Nietzschean Vitalism (Biology + Biography + Force)
**What:**
- *Biological:* Population genetics papers, ancestral DNA, archaeological excavation reports, material culture studies
- *Individual:* Biographies, autobiographies, diaries, letters, oral histories, memoirs
- *Force:* Primary writings of key figures, contemporary accounts, military/political records
**Where:** PubMed/Google Scholar, Vietnamese archaeology journals, EFEO, major library collections, published complete works.
**Agent workflow:** Search PubMed → archaeological databases → compile biographies → gather primary writings.

### For Marxist Class Analysis
**What:** Economic records, tax/land ownership, production statistics, labor records, trade records, colonial administrative records, census data.
**Where:** French colonial archives, CIA FOIA, Vietnamese government statistics, academic economic histories.
**Agent workflow:** Search French colonial archives → CIA FOIA → academic databases → cross-reference with VSTB class analysis.

### For Covert + Luttwak
**What:** CIA FOIA releases, National Security Archive, declassified military documents, French intelligence archives, journalist accounts, memoirs, strategic assessments.
**Where:** CIA FOIA Reading Room, National Security Archive, Vietnam Center (Texas Tech), LBJ/JFK Libraries, published memoirs.
**Agent workflow:** Search CIA FOIA → National Security Archive → academic databases → cross-reference official strategy with ground truth.

## Phase 2: Source Processing
1. First pass — content extraction (what happened)
2. Second pass — lens extraction (what the four lenses reveal)
3. Tag with metadata (source type, period, lens signal, reliability)
4. Extract key quotes, data points, insights
5. Note gaps and questions

## Phase 3: Lens Analysis
Write one analysis per lens per period:
- Burckhardt (500-1000 words): Cultural themes, Zeitgeist synthesis
- Nietzschean Vitalist (500-1000 words): Biological substrate, key figure biographies, vital force assessments
- Class (500-1000 words): Class structure, ownership, labor, conflict
- Covert+Strategic (500-1000 words): Hidden structures, Luttwak strategic analysis

## Phase 4: Synthesis
1. Convergence analysis — where lenses agree (= strongest claims)
2. Divergence analysis — where they contradict (= most interesting findings)
3. Genealogical thread — what made this period possible, what it made possible
4. Period portrait — integrated narrative (1500-3000 words)

## Phase 5: Verification
1. Three-source rule — no claim on fewer than 3 independent sources
2. Language triangulation — check across French, Vietnamese, English
3. Source-type triangulation — government + memoir + newspaper
4. Temporal triangulation — contemporary + memoir + modern analysis
5. du Berrier test — for covert claims, 5-question verification

## Agent Coordination
- **Agent A: Burckhardt specialist** — Cultural history, Zeitgeist
- **Agent B: Vitalist specialist** — Biology, biography, force
- **Agent C: Class specialist** — Economic analysis, material structure
- **Agent D: Covert specialist** — Intelligence, strategic logic
- Parallel source gathering → independent analysis → cross-review → synthesis session
