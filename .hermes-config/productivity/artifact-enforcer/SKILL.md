## Purpose
Prevents valuable work from disappearing into chat history by making artifact creation the default final step.

## When to Use
- End of any research, analysis, or planning task.
- Can be called manually or added as the last step in other skills.

## Workflow
1. Complete the main task.
2. Format the deliverable cleanly.
3. Save as artifact with naming convention: `project-date-purpose` (e.g., `vietnam-2026-06-07-sources`).
4. Confirm the artifact was created and provide its name to the user.

## Output Contract
Every important task must end with an artifact, not just chat text.
