# Epidemiology Study Design — Confusability Cluster

TempMoon consistently mixes up these three designs across review sessions. This reference file provides the comparison table and memory hooks.

## Comparison Table

| | Cohort | Case-Control | Cross-Sectional |
|---|---|---|---|
| **Direction** | Forward (exposure → outcome) | Backward (outcome → look back at exposure) | Snapshot (exposure + outcome measured simultaneously) |
| **Measure** | Relative Risk (RR) | Odds Ratio (OR) | Prevalence Ratio |
| **Preferred when** | Exposure is rare | Outcome is rare | Quick assessment, hypothesis generation |
| **Estimates** | Incidence | Cannot estimate incidence directly | Prevalence (existing cases) |
| **Speed/Cost** | Slow, expensive | Fast, cheap | Fast, moderate cost |
| **Key weakness** | Expensive, long follow-up, loss to follow-up | Recall bias, control selection critical | Temporal ambiguity (can't establish causation) |
| **Causation?** | Strongest for causation (if well-designed) | Suggestive, not definitive | Cannot establish causation |

## Memory Hooks

- **Cohort** = **C**ohort follows **C**hosen people **F**orward → **R**elative **R**isk
- **Case-Control** = **C**ases vs **C**ontrols, look **B**ackward → **O**dds **R**atio
- **Cross-Sectional** = **C**ross-section at one point → **P**revalence, no **P**rior sequence

## Common Errors (from review sessions)

1. Saying case-control "generates incidence" — that's cohort. Case-control CANNOT estimate incidence.
2. Saying cohort is "backwards looking" — cohort is forward. Retrospective cohort uses historical data but analysis still flows forward from exposure → outcome.
3. Saying cross-sectional "measures incidence" — it measures prevalence (existing cases at one time point).
4. Confusing "rare exposure" (cohort preferred) with "rare outcome" (case-control preferred).
