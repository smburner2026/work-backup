## Source Workflow

1. **Acquisition** — Locate and obtain source material
2. **Cataloging** — Add to source list with metadata (period, lens, language, format)
3. **Reading** — Analyze source with six lenses in mind
4. **Extraction** — Pull key insights, quotes, data points
5. **Integration** — Incorporate into project notes and writing
