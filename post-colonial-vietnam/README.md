## Scope — To Be Defined

"Post-colonial Vietnam" is broad. Some possible angles:

| Angle | Focus | Period |
|-------|-------|--------|
| **Historical** | From Geneva Accords (1954) through war, reunification, to Đổi Mới (1986) and modern era | 1954–present |
| **Political** | State formation, ideology, governance models post-French rule | 1945–present |
| **Economic** | Central planning to market reforms — the Đổi Mới story | 1975–present |
| **Cultural/Lit** | Vietnamese literature, film, art in the post-colonial context | 1954–present |
| **Comprehensive** | Multiple lenses, potentially a book/manifest | |
